# Belchior --- Tributo

Site estático desenvolvido como projeto de estudo e parte do meu
portfólio de evolução em desenvolvimento web.

A proposta foi criar uma página de tributo ao cantor e compositor
Belchior, explorando composição visual, tipografia, organização de
conteúdo e responsividade para diferentes tamanhos de tela.

## 🎯 Objetivo

Este projeto foi desenvolvido principalmente para praticar e consolidar
conhecimentos de:

-   HTML semântico
-   CSS
-   Flexbox
-   Responsividade
-   Media Queries
-   Tipografia e hierarquia visual
-   Variáveis CSS
-   Backgrounds e imagens
-   Organização e composição de layouts
-   Integração de conteúdo externo com Spotify

## 🖥️ Sobre o projeto

A página é composta por diferentes seções apresentadas de forma
contínua:

-   **Hero:** apresentação do Belchior, com destaque para a fotografia e
    a frase "Apenas um rapaz latino-americano".
-   **Biografia:** breve apresentação da trajetória do artista.
-   **Álbum mais popular:** destaque para o álbum *Alucinação*, lançado
    em 1976, acompanhado de um player incorporado do Spotify.
-   **Suas frases populares:** seleção de frases relacionadas às obras
    de Belchior.
-   **Footer:** encerramento da página e identificação do projeto.

## 🎨 Identidade visual

O projeto utiliza uma estética predominantemente monocromática, com
preto, branco, tons de creme e detalhes em dourado/bege.

A tipografia foi pensada para criar contraste entre uma estética
editorial e uma interface moderna:

-   **Cormorant Garamond:** títulos e elementos de maior destaque.
-   **Space Grotesk:** textos, navegação e informações complementares.

A proposta visual busca transmitir uma atmosfera documental e literária,
mantendo a interface simples e objetiva.

## 📱 Responsividade

O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela.

No desktop, as informações são distribuídas horizontalmente para
aproveitar o espaço disponível. No mobile, os elementos são
reorganizados verticalmente, mantendo a hierarquia visual e a
legibilidade.

## 🛠️ Tecnologias

-   HTML5
-   CSS3
-   JavaScript
-   Spotify Embed
-   Figma

## 📚 Contexto

Este não é um projeto comercial. Ele foi criado exclusivamente para
estudo e para registrar minha evolução durante o aprendizado de
desenvolvimento web.

A prioridade foi colocar em prática os fundamentos de HTML e CSS e
concluir um projeto visualmente consistente, sem adicionar
funcionalidades desnecessárias.
